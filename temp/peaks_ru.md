# FTIR-кодекс: интерпретация пиков 📈

> Схема характерных частот (стр. 1–2 исходника) — см. приложенное изображение, НЕ перерисовывать.
> Легенда: v — очень, s — сильная, m — средняя, w — слабая, br — широкая.
> ν — валентные, δ — деформ. в плоскости, γ — внеплоскостные, ρ — rocking/wag.

## 1. Правила дискриминации пиков 🔍

1. **C=O (1870–1650): сначала сопутствующие полосы.**
   - Ангидрид: дублет 1870–1790 + 1765–1725 (νas/νs).
   - Хлорангидрид: ~1800, нет OH/NH.
   - Эфир (эстер): 1750–1740 + сильная C–O 1300–1000, нет OH.
   - Альдегид: 1740–1720 + дублет Ферми ν(CHO) 2750/2650 (нет у кетонов).
   - Кетон: 1720–1700, нет CHO-дублета, нет OH.
   - Кислота: 1710–1690 + очень широкий ν(OH) 3100–2400, перекрывает C–H.
   - Амид: 1690–1630 + N–H 3500–3100 + Амид II 1640–1475.
   - Сопряжение: −20…−30 см⁻¹ для альдегидов/кетонов/кислот; енолы β-кетоэфиров 1655–1635.
2. **OH-типы:** свободный 3700–3600 (острый); H-связь 3420–3250 (широкая); COOH 3100–2400 (оч. широкий); NH3+ 3200–3000 (оч. широкий, соли аминов 2750–2350).
3. **N–H vs O–H:** N–H уже и слабее; первичные NH2 — дублет 3360/3320 (νas/νs); вторичные — одна полоса; амиды + Амид II.
4. **Тройная связь/кумулены (2300–1900):** нитрил 2260–2200 (острая); азид 2175–2115 (оч. сильная); изоцианат 2285–2250 (сильная, шире); изоцианид 2190–2130; диазоний 2300–2230; терминальный алкин 2160–2080 + ≡C–H 3300; внутренний алкин 2260–2190 (слабая в ИК, сильная в Рамане); аллен 1980–1950 (νas C=C=C).
5. **Алкены/ароматика:** =C–H 3100–3000; C=C 1680–1630; кольцо 1615/1590/1580/1475/1450 (1600+1475 — пара); обертоны 2000–1650 — паттерн замещения.
   - Винил: 990 (vs) + 910 (vs); винилиден: 890 (vs); транс: 965 (vs); цис: 770–690.
   - Замещение бензола: моно 770–730 + 710–690; орто 800–690; мета 810–750 + 710–690 + ~880; пара 850–830; 1,2,4 — 860–790 (2 полосы); 1,3,5 — 840–800 + 690–670; 1,2,3 — 825–805 + 815–810.
6. **NO2:** две сильные: νas 1560–1510 + νs 1390–1350 (аром. ниже алифат. по νas, выше по νs).
7. **S=O-паттерны:** сульфоны 1335–1295 + 1170–1140; сульфонамиды 1360–1335 + 1170–1145; сульфонилхлориды 1410–1360 ⚠ + 1200–1165; сульфокислоты 1245–1155 + 1080–1040; сульфоксиды ~1170–1140/1050.
8. **C–O (1300–1000):** эфиры (эстеры) — две сильные (νas C–O–C 1300–1150 + νs); простые эфиры — одна 1150–1070; спирты + ν(OH) 3600–3200; фенолы + 1285–1240.
9. **Галогены:** C–F 1400–1000 (vs); C–Cl 800–600; C–Br 710–570; C–I 600–465.
10. **Раман-комплемент:** симметричные колебания (S–H, C≡C, S–S, C–S) сильны в Рамане, слабы в ИК — используй для дизамещённых алкинов/дисульфидов.
11. **Ферми-резонансы:** альдегид 2750/2650; изопропил/гем-диметил дублет 1385/1370; циклопентанон и др. — не принимать за истинные группы.
12. **CH2/CH3:** δas CH3 + δ CH2 1465–1440; δs CH3 1380–1370; ρ(CH2) n≥4 — 740–720 (интенсивность ∝ длине цепи).
